YlvaOS

Elin内のコンピューター家具から起動する、実Linux VMベースの小さなOSです。テキストコンソール、軽量デスクトップ、Wine、任意ネットワーク接続を備えています。

+----------------------------------+
|  Elin computer  ->  YlvaOS      |
|  ver 0.1.0       real Linux VM  |
|  console / desktop / Wine       |
+----------------------------------+
はじめる コマンド Desktop Elona Network 保存場所 配布

はじめる

1. コンピューターを使う 手持ちでも地面に設置した状態でも、Elinのコンピューター家具を使用するとYlvaOSウィンドウが開きます。
2. 初回警告に同意 初回のみ、実Linux互換OSをPC上で動かすことへの警告が表示されます。同意後にセットアップへ進みます。
3. ユーザー作成 ユーザー名とパスワードを入力します。パスワードは空でも構いません。次回以降はログイン画面から始まります。

YlvaOSのデータはコンピューターごとではなく全セーブ共通です。LocalLow配下のYlvaOSフォルダに保存されます。

独自コマンド一覧

Desktop
軽量デスクトップへ切り替えます。Openbox、tint2、xtermを使うGUIモードです。
Kernel
デスクトップからテキストコンソールへ戻ります。デスクトップ端末内で実行できます。
Terminal [title]
デスクトップ上にYlvaOS Terminalを開きます。右クリックメニューや Ctrl+Alt+T でも起動できます。
YlvaOS status
YlvaOSの状態とLinux kernel情報を表示します。
YlvaOS set memory <MiB>
VMのメモリ割り当てを変更します。反映はYlvaOS再起動後です。例: YlvaOS set memory 4096
YlvaOS set disk <MiB>
仮想ディスクの目標サイズを拡張します。縮小はできません。反映は次回VM起動時です。
ConnectNetwork
英語のリスク警告を表示し、yes と入力した場合だけ、そのVMセッションでインターネット接続を有効化します。
YlvaOS setup wine
Wine prefix、音声経路、日本語表示用のCP932/フォント設定を初期化します。Elonaを初めて動かす前に実行します。
YlvaOS setup font
fontconfig cacheとWineの日本語フォント置換を再適用します。
YlvaOS setup audio
PulseAudioの ylva sink とMIDI再生用FluidSynthを起動します。

小文字エイリアスとして desktop、kernel、terminal、connectnetwork も用意されています。

Desktop Mode

テキストコンソールで Desktop を実行すると、YlvaOSウィンドウ内に軽量デスクトップが表示されます。入力はElinウィンドウ内からQEMUのVNC/RFB経由でゲストへ送られます。

  • Ctrl+Alt+T: YlvaOS Terminalを開く
  • Ctrl+Alt+K: テキストコンソールへ戻る
  • Ctrl+V: ホストのクリップボード文字列をYlvaOSへ貼り付ける
  • Xボタン: YlvaOSウィンドウを閉じる

Elonaを入れて起動する

Elona本体は配布条件を確認し、ユーザー自身で用意してください。ホスト側のImportフォルダへElonaフォルダを置くと、YlvaOSから読み取り専用ドライブとして見えます。

C:\Users\<ユーザー名>\AppData\LocalLow\Lafrontier\Elin\YlvaOS\Import\elona

YlvaOS内でコピーする例:

mkdir -p ~/Import
dev=/dev/vdb1
[ -b "$dev" ] || dev=/dev/vdb
doas mount -t vfat -o ro,uid=$(id -u),gid=$(id -g) "$dev" ~/Import
cp -r ~/Import/elona ~/Elona
doas umount ~/Import

デスクトップへ入り、Wineを初期化してからElonaのフォルダで起動します。

Desktop
YlvaOS setup wine
cd ~/Elona
wine elona.exe

Network

YlvaOSは既定でネットワーク無効です。パッケージ追加などで必要なときだけ ConnectNetwork を実行します。

ネットワークを有効にすると、ゲスト内プログラムが外部サーバーへ接続し、VM内データを変更または送信できるようになります。警告文を読み、理解した場合だけ yes と入力してください。

ConnectNetwork
doas apk update
doas apk add <package>

保存場所

YlvaOSの実行データはElinのLocalLow配下に作られます。別セーブデータでも同じYlvaOSデータを使います。

C:\Users\<ユーザー名>\AppData\LocalLow\Lafrontier\Elin\YlvaOS
├─ state.json
├─ vmconfig.json
├─ vm\disk.qcow2
├─ vm\assets\vmlinuz
├─ vm\assets\initrd.img
├─ Tools\qemu\
└─ Import\

YlvaOSからホスト全体へアクセスする経路は用意していません。Importフォルダだけを読み取り専用で渡します。

rootfs更新後も既存の vm\disk.qcow2 は自動上書きされません。日本語表示や音声設定の変更を取り込むには、必要なデータをバックアップしてから既存ディスクを削除し、同梱root diskを再展開してください。

GitHub公開と配布

公開リポジトリでは、QEMU、kernel/initrd、生成済みroot disk、ローカルElonaコピーは追跡しません。配布時はRelease用zipに必要なランタイムを含めるか、ユーザー向けにビルド手順を案内してください。

  • rootfs再生成: python .\Tools\build_ylvaos_image.py --force
  • MODビルド: dotnet build .\YlvaOS\YlvaOS.csproj -c Release -v:minimal
