YlvaOS

YlvaOS is a small real-Linux VM operating system launched from computer furniture inside Elin. YlvaOS 0.05 is based on Alpine Linux 3.24.1 and provides both kernel console mode and a lightweight desktop mode.

YlvaOS Overview

YlvaOS is a Linux-compatible OS environment shown inside an Elin in-game window. The MOD starts an isolated QEMU virtual machine, then draws the guest display into the computer window inside Elin.

Real Linux VM YlvaOS boots a Linux kernel and an Alpine Linux based userland inside a QEMU virtual machine.
In-Game Display Both the kernel text console and the lightweight desktop are displayed inside the Elin UI.
Safer Default State Networking is disabled by default. The host-to-guest Import folder is exposed as read-only.

This MOD runs a real Linux-compatible operating system on your PC. It is intended for users who understand Linux or Linux-derived systems.

PC Resources Used

Supported OS
Windows only, due to the bundled files and the current runtime method.
Memory
The default allocation is 4096 MiB. Change it with YlvaOS set memory <MiB> or YlvaOS Settings. The change applies after rebooting YlvaOS.
Virtual Disk
The default virtual disk size is 16384 MiB. Expand it with YlvaOS set disk <MiB>. Shrinking is not supported.
CPU
The VM uses 2 vCPUs by default. Actual host load depends on the applications running inside the guest.
Display
The desktop defaults to 1024x768 at 24 FPS. Use YlvaOS set desktop <WxH> and YlvaOS set fps <FPS> to change these values.
Network
Networking is disabled by default. Run ConnectNetwork, read the English warning, and type yes to enable it for the current VM session.

Where Data Is Stored and How to Delete It

YlvaOS data is shared by all computer furniture and all Elin save files. It is stored under Elin's LocalLow directory.

C:\Users\<UserName>\AppData\LocalLow\Lafrontier\Elin\YlvaOS
├─ state.json
├─ vmconfig.json
├─ vm\disk.qcow2
├─ vm\assets\vmlinuz
├─ vm\assets\initrd.img
├─ Tools\qemu\
├─ snapshots\
└─ Import\
  • vm\disk.qcow2 stores Linux users, home directories, installed packages, and other guest data.
  • vmconfig.json stores memory, disk, desktop resolution, FPS, and related settings.
  • snapshots stores root disk snapshots. Settings files and the Import folder are not included.
  • Import is a read-only host-to-guest folder used to pass files into YlvaOS.

To reset or remove YlvaOS data, close Elin and YlvaOS, then delete the entire YlvaOS folder. This removes Linux users, passwords, home directories, and installed packages.

Custom Commands

Desktop
Switches to lightweight desktop mode.
Kernel
Returns from desktop mode to kernel console mode.
Terminal [title]
Opens a YlvaOS Terminal window on the desktop. Ctrl+Alt+T also opens it.
AppLauncher
Opens a lightweight launcher for Terminal, File Manager, Settings, Text Editor, System Monitor, and other commands. Ctrl+Alt+Space also opens it.
TextEditor [file]
Opens a lightweight nano-first editor on the desktop or console. vim is also bundled. Files under ~/Import open read-only.
Settings
Opens YlvaOS Settings.
Files [path]
Opens File Manager. If no path is provided, it opens near the home directory.
PackageManager
Opens a helper for searching, updating, installing, and removing Alpine apk packages.
RepairMode
Opens the repair helper for desktop config, user config, package state, and serial login recovery.
YlvaOS status
Shows YlvaOS and Linux kernel status.
YlvaOS update
Checks the installed MOD directory and updates YlvaOS if a newer bundled OS version is available, then reboots. Startup also reports when a newer bundled version is available.
YlvaOS launch [app]
Opens Application Launcher or starts the named fixed entry/PATH command.
YlvaOS edit [file]
Opens Text Editor. The default EDITOR / VISUAL values are set to TextEditor.
YlvaOS settings
Opens YlvaOS Settings.
YlvaOS files [path]
Opens File Manager.
SystemMonitor / YlvaOS monitor
Shows CPU, memory, disk space, network state, and process list in a lightweight monitor. Ending a process requires confirmation.
SnapshotManager / YlvaOS snapshot ...
Lists, creates, restores, and deletes root disk snapshots. Create, restore, and delete are available only while the VM is stopped.
YlvaOS package ...
Provides search, update, install, and remove. When networking is disabled, it points you to ConnectNetwork; logs are written to ~/YlvaOS/logs/package.log.
YlvaOS repair ...
Provides desktop, user-config, packages, safe-console, and login. Destructive repairs back up affected files under ~/YlvaOS/backups first.
YlvaOS set memory <MiB>
Changes the VM memory allocation. The change applies after rebooting YlvaOS.
YlvaOS set disk <MiB>
Expands the target virtual disk size. Shrinking is not supported.
YlvaOS set desktop <WxH>
Changes the desktop resolution. Example: YlvaOS set desktop 1280x720
YlvaOS set fps <FPS>
Changes the target desktop refresh FPS.
YlvaOS setup wine
Initializes the Wine environment.
YlvaOS setup wine directmusic
Installs DirectMusic-related runtime components through winetricks after explicit consent for old Windows game MIDI playback. Run ConnectNetwork first.
YlvaOS setup font
Reapplies font settings for Japanese text rendering.
YlvaOS setup audio
Initializes desktop audio and MIDI playback support.
ConnectNetwork
Enables Internet access for the current VM session only after the user accepts the risk warning.
vm status / vm paths / vm start / vm stop
Helper commands used in the pre-VM management console.

Some commands also have lowercase aliases, such as desktop, kernel, terminal, launcher, texteditor, editor, settings, files, packagemanager, repairmode, and connectnetwork. Snapshot commands can also be used from the pre-VM management console with YlvaOS snapshot list, YlvaOS snapshot create name memo, YlvaOS snapshot restore name, and YlvaOS snapshot delete name.

Kernel Mode Controls

Kernel mode is the text console shown after YlvaOS starts. You can run normal Linux commands, YlvaOS custom commands, and apk operations through Package Manager Helper.

  • Typing: focus the YlvaOS window inside Elin, then type normally.
  • Ctrl+V: pastes text from the host clipboard into YlvaOS.
  • Esc: sent to YlvaOS instead of closing the Elin-side window.
  • Desktop: switches to lightweight desktop mode.
  • reboot: reboots YlvaOS. Use this after changing memory or display settings.
  • poweroff, shutdown, or exit: shuts down YlvaOS. The Elin-side YlvaOS window closes after shutdown.

Desktop Mode Controls

Desktop mode is a lightweight GUI environment running inside YlvaOS. It provides Openbox windows, YlvaOS Terminal, YlvaOS Settings, File Manager, Package Manager, System Monitor, Snapshot Manager, and Repair Mode.

  • Ctrl+Alt+T: opens YlvaOS Terminal.
  • Ctrl+Alt+K: returns to kernel mode. You can also type Kernel in a terminal.
  • Ctrl+V: pastes text from the host clipboard.
  • Right click: opens the desktop menu for Terminal, Settings, File Manager, Package Manager, System Monitor, Snapshot Manager, Repair Mode, and related actions.
  • Title bar buttons: minimize, maximize, or close desktop windows.
  • YlvaOS window X button: closes the in-game display window. If the VM is still running, the next use resumes the screen from where you left it.
