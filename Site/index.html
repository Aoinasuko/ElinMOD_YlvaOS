YlvaOS

Elin内のコンピューター家具から起動する、実Linux VMベースの小さなOSです。YlvaOS 0.04はAlpine Linux 3.24.1をベースに、カーネルモードと軽量デスクトップモードを提供します。

YlvaOSの概要

YlvaOSは、Elinのゲーム内ウィンドウに表示されるLinux互換OS環境です。MODはQEMUで隔離された仮想マシンを起動し、その画面をElin内のコンピューターウィンドウへ描画します。

実Linux VM Linux kernelとAlpine Linuxベースのユーザーランドを、QEMUの仮想マシン内で起動します。
ゲーム内表示 カーネルモードのテキスト画面と、軽量デスクトップモードをElin内のウィンドウへ表示します。
安全寄りの初期状態 ネットワークは既定で無効です。ホストからゲストへ渡すImportフォルダは読み取り専用です。

このMODは実際にPC上でLinux互換OSを動かします。Linuxや派生OSの操作を理解している方向けです。

使用するPCリソース

対応OS
同梱ファイルと実行方式の都合上、Windowsのみを対象にしています。
メモリ
既定は4096 MiBです。YlvaOS set memory <MiB> またはYlvaOS Settingsで変更でき、再起動後に反映されます。
仮想ディスク
既定は16384 MiBです。YlvaOS set disk <MiB> で拡張できます。縮小はできません。
CPU
既定で2 vCPUを使用します。実際の負荷はゲスト内で実行するアプリケーションに依存します。
画面描画
デスクトップ解像度は既定1024x768、描画更新は既定24 FPSです。YlvaOS set desktop <WxH> と YlvaOS set fps <FPS> で変更できます。
ネットワーク
既定では無効です。ConnectNetwork 実行後、英文警告に対して yes と入力した場合のみ、そのVMセッションで有効になります。

どこにデータが保存されるか、削除方法

YlvaOSのデータはコンピューター家具ごとではなく、すべてのコンピューターとセーブデータで共通です。保存場所はElinのLocalLow配下です。

C:\Users\<ユーザー名>\AppData\LocalLow\Lafrontier\Elin\YlvaOS
├─ state.json
├─ vmconfig.json
├─ vm\disk.qcow2
├─ vm\assets\vmlinuz
├─ vm\assets\initrd.img
├─ Tools\qemu\
├─ snapshots\
└─ Import\
  • vm\disk.qcow2 にはLinux側のユーザー、ホームディレクトリ、インストール済みパッケージなどが保存されます。
  • vmconfig.json にはメモリ、ディスク、デスクトップ解像度、FPSなどの設定が保存されます。
  • snapshots にはYlvaOSのroot diskスナップショットが保存されます。設定ファイルやImportフォルダは含まれません。
  • Import はホストからYlvaOSへファイルを渡すための読み取り専用フォルダです。

データを削除または初期化したい場合は、ElinとYlvaOSを終了してから YlvaOS フォルダ全体を削除してください。Linux側のユーザー、パスワード、ホームディレクトリ、インストール済みパッケージも削除されます。

独自コマンド一覧

Desktop
軽量デスクトップモードへ切り替えます。
Kernel
デスクトップモードからカーネルモードへ戻ります。
Terminal [title]
デスクトップ上にYlvaOS Terminalを開きます。Ctrl+Alt+T でも起動できます。
Settings
YlvaOS Settingsを開きます。
Files [path]
File Managerを開きます。パスを省略した場合はホーム周辺を開きます。
PackageManager
Alpineのapkパッケージを検索、更新、インストール、削除するヘルパーを開きます。
RepairMode
デスクトップ設定、ユーザー設定、パッケージ状態、シリアルログインの修復ヘルパーを開きます。
YlvaOS status
YlvaOSとLinux kernelの状態を表示します。
YlvaOS update
MODディレクトリ内の更新データを確認し、YlvaOSのバージョンが上がっていれば更新して再起動します。新しい同梱版がある場合は起動時にも通知されます。
YlvaOS settings
YlvaOS Settingsを開きます。
YlvaOS files [path]
File Managerを開きます。
SystemMonitor / YlvaOS monitor
CPU、メモリ、ディスク残量、ネットワーク状態、プロセス一覧を軽量モニターで表示します。プロセス終了時は確認が必要です。
SnapshotManager / YlvaOS snapshot ...
root diskスナップショットの一覧、作成、復元、削除を行います。作成、復元、削除はVM停止中のみ実行できます。
YlvaOS package ...
search、update、install、remove を提供します。ネットワーク無効時は ConnectNetwork の案内を表示し、実行ログは ~/YlvaOS/logs/package.log に保存します。
YlvaOS repair ...
desktop、user-config、packages、safe-console、login を提供します。破壊的な修復は ~/YlvaOS/backups へバックアップしてから実行します。
YlvaOS set memory <MiB>
VMのメモリ割り当てを変更します。反映はYlvaOS再起動後です。
YlvaOS set disk <MiB>
仮想ディスクの目標サイズを拡張します。縮小はできません。
YlvaOS set desktop <WxH>
デスクトップ解像度を変更します。例: YlvaOS set desktop 1280x720
YlvaOS set fps <FPS>
デスクトップ描画更新の目標FPSを変更します。
YlvaOS setup wine
Wine環境を初期化します。
YlvaOS setup wine directmusic
古いWindowsゲームのMIDI再生向けに、同意後にwinetricks経由でDirectMusic関連ランタイムを導入します。事前に ConnectNetwork が必要です。
YlvaOS setup font
日本語表示向けのフォント設定を再適用します。
YlvaOS setup audio
デスクトップ音声とMIDI再生向けの音声設定を初期化します。
ConnectNetwork
リスク警告に同意した場合のみ、そのVMセッションでインターネット接続を有効にします。
vm status / vm paths / vm start / vm stop
VM起動前の管理コンソールで使う補助コマンドです。

一部コマンドには小文字エイリアスがあります。例: desktop、kernel、terminal、settings、files、packagemanager、repairmode、connectnetwork。スナップショット操作はVM起動前の管理コンソールでも YlvaOS snapshot list、YlvaOS snapshot create 名前 メモ、YlvaOS snapshot restore 名前、YlvaOS snapshot delete 名前 を使用できます。

カーネルモードの操作

カーネルモードは、YlvaOS起動直後に表示されるテキストコンソールです。Linuxの通常コマンド、YlvaOS独自コマンド、Package Manager Helper経由のapk操作などを入力できます。

  • 文字入力: Elin内のYlvaOSウィンドウを選択してキーボード入力します。
  • Ctrl+V: ホスト側クリップボードの文字列を貼り付けます。
  • Esc: Elin側で閉じる操作には使わず、YlvaOS側へ送信されます。
  • Desktop: 軽量デスクトップモードへ切り替えます。
  • reboot: YlvaOSを再起動します。メモリや画面設定の変更後に使用します。
  • poweroff、shutdown、exit: YlvaOSを終了します。終了後、Elin内のYlvaOSウィンドウは閉じます。

デスクトップモードの操作

デスクトップモードは、YlvaOS内で動く軽量GUI環境です。Openboxベースのウィンドウ、YlvaOS Terminal、YlvaOS Settings、File Manager、Package Manager、System Monitor、Snapshot Manager、Repair Modeを使用できます。

  • Ctrl+Alt+T: YlvaOS Terminalを開きます。
  • Ctrl+Alt+K: カーネルモードへ戻ります。端末内で Kernel と入力しても戻れます。
  • Ctrl+V: ホスト側クリップボードの文字列を貼り付けます。
  • 右クリック: デスクトップメニューを開き、Terminal、Settings、File Manager、Package Manager、System Monitor、Snapshot Manager、Repair Modeなどを起動できます。
  • タイトルバーのボタン: 各ウィンドウを最小化、最大化、閉じることができます。
  • YlvaOSウィンドウ右上のX: Elin内の表示ウィンドウを閉じます。VMが動作中の場合、次回使用時に閉じた時点の画面へ戻ります。
